# Northstar Training Service

Fictional, intentionally small repository for defensive CI/security tooling exercises.
No production service, secrets or personal data are present.

Tasks may include:
- document-quality checks,
- dependency manifest/SBOM parsing,
- secret-pattern scanning using a dummy sentinel,
- secure-coding review,
- test and CI workflow validation.

Do not use real API keys. The string `TRAINING_ONLY_NOT_A_SECRET_0000` is a harmless fixture sentinel.
